# Intent

## What I'm building
An interactive math learning website — Khan Academy meets Duolingo — with lessons, quizzes, minigames, sound, and lots of visuals.

## Target audience
- **Now:** grades **4–6** (upper elementary).
- **Later (maybe):** grades **1–3** (lower elementary).
- Focus for now is the 4–6 band.

## Note on direction
Originally scoped for 7th grade. Shifting the topics down to grades 4–6 while keeping the exact same website design, features, and interactivity.

## Core features (already built, to be kept)
- Homepage + top-tab navigation
- Units, each with lessons + quizzes (Khan Academy style)
- Interactive visuals in every lesson
- Arcade with minigames
- Gamification: XP, levels, streaks, badges, sound effects, confetti
- Progress dashboard

## Key differentiator
More interactive than Khan Academy — hands-on visuals and games are the main draw.

## Status
Grades 4–6 topic shift in planning. Same site, new grade-appropriate content.
