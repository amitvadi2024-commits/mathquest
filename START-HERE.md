# Start Here

A plain-English guide to building this site with Cowork. No coding experience needed.

## How this works
You don't have to write code. You tell me (Claude) what you want in plain English,
and I build the files in this folder. You review, then ask for changes.

This folder (`math-website`) is shared between us. Anything I create here, you can see
and open on your computer.

## The plan (simple version)
1. **Plan** — decide topics and look (done: see Intent.md and Ideas.md).
2. **Build a starter site** — one working webpage with a homepage and topic tabs.
3. **Add a topic** — pick one (e.g. fractions) and build a real interactive lesson + quiz.
4. **Repeat** — add more topics one at a time.
5. **Polish** — points, badges, progress tracking.

We go one small step at a time so it never feels overwhelming.

## How to open the site once it exists
The site will be a file called `index.html`. Double-click it and it opens in your
web browser (Chrome, Edge, etc.). No installing anything.

## What I need from you to start
- Just say the word **"approval"** when you want me to build the starter site.
- (Per your project rule, I won't write site code until you give that word.)

## Tip
You can always ask me things like:
- "Make the homepage blue and friendly looking"
- "Add a fractions quiz with 5 questions"
- "Explain what this file does"
